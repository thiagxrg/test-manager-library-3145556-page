Manager Library

Biblioteca universitaria ordenada y medible

Frontend de presentación estática. El sistema completo combina catálogo, miembros, préstamos, devoluciones, vencidos y reporte de más prestados.

Ver capacidades Ver arquitectura

Catálogo

Búsqueda por texto y categoría, portadas, ISBN único y copias disponibles.

Miembros

Alta de socios por número de documento y conteo de préstamos activos.

Préstamos

Hasta 3 libros, sin duplicados, bloqueo si hay vencidos o sin stock.

Devoluciones

Devolución por ítem con reposición de copia y estado calculado.

Vencidos

Listado operativo con días de retraso para seguimiento.

Reporte

Título y categoría congelados, ordenado por préstamos y título.

Arquitectura

Backend en PHP/Laravel con dominio desacoplado, puertos de salida, adaptadores Eloquent y bootstrap centralizado. Frontend React consumiendo la API REST. Infraestructura con Docker y PostgreSQL vacío hasta migración.
